# Security Policy

This is a portfolio systems project, but security issues are still handled seriously.

## Supported Versions

The `main` branch is the only supported line.

## Reporting a Vulnerability

Open a private security advisory on GitHub if available. If not, open an issue with minimal reproduction details and avoid posting sensitive traffic captures, secrets, or private infrastructure details.

Useful reports include:

- Crash or denial-of-service inputs
- Admin endpoint exposure risks
- Unsafe parsing behavior
- Resource exhaustion paths
- Build or dependency vulnerabilities

Do not include secrets, production IPs, or credentials in reports.
